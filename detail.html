Creative Workshop Directory

A student project exploring how Figma wireframes, CSS Grid, and Flexbox can create a clear workshop directory across desktop and mobile.

The challenge

The task was to design a workshop directory that clearly presents upcoming sessions and workshop information. The layout needed to work on desktop and mobile, using CSS Grid for the main sections and Flexbox within cards.

The solution

I created desktop and mobile wireframes in Figma, then built the page with HTML and CSS. A two-column hero highlights the main information, while workshop cards stack vertically on mobile.

Workshop Directory — Desktop and Mobile

The outcome

The finished page presents workshop information in a responsive layout. Grid controls the hero and gallery, while Flexbox keeps card buttons aligned. The project helped me practise turning Figma wireframes into HTML and CSS.
